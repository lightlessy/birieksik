# MVP Scope

## Must Have
- Landing page
- İTÜ email login
- User profile creation
- Active request feed
- Create request form
- Request detail page
- Apply to request
- Owner dashboard
- Accept / reject application
- Basic status management: open, filled, cancelled, expired

## Must Not Have in MVP
- Native mobile app
- App Store / Play Store deployment
- Map view
- Swipe
- Public DM
- Profile browsing
- Gender filter
- AI matching
- Push notifications
- Advanced chat
- Ratings
- Payment

## MVP Success Criteria
Technical success:
- A user can create a request.
- Another user can apply.
- The owner can accept the applicant.

Product success:
- 100 verified users in 7 days.
- 30 requests created.
- 10 real-world matches.
