# Biri Eksik / +1 İTÜ - Project Brief

## One-line Summary
Biri Eksik is a campus-only web app where verified İTÜ students can post real-time requests to find missing people for activities such as okey, sports, studying, food, or coffee.

## Core Problem
University students often need one or more people to complete an activity, but existing social apps feel too broad, dating-oriented, or unsafe. The app solves the "one person missing" problem in a trusted campus context.

## MVP Goal
Allow an İTÜ student to:
1. Sign in with an İTÜ email.
2. Create an activity request.
3. See active requests.
4. Apply to join a request.
5. Let the request owner accept or reject applicants.

## Positioning
This is not a dating app. It is an activity coordination tool.

## Target Users
İstanbul Technical University students.

## First Use Cases
- Okey / board game: “We are 3 people, need a 4th.”
- Sports: “Need 2 players for basketball.”
- Studying: “Looking for people to study FIZ102E.”
- Food / coffee: “Looking for someone to join.”

## Core Rule
The app shows activities, not random nearby people.

## MVP Tech Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase Postgres
- Vercel
